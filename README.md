# LegalRAG 私有合同PDF智能问答工具

## 一、项目简介
基于 DeepSeek 大模型 + 本地TF-IDF检索的私有合同PDF智能问答工具，无文档上传、无向量数据库、无本地大模型，纯轻量化本地部署，回答不编造、低幻觉，适合法律合同、办公文档等私有知识库快速搭建。

## 二、版本更新 V1.1
本次迭代核心优化：新增多轮上下文对话、修复链路报错、架构解耦、通用化适配任意PDF

- 支持多轮追问，可识别「还有呢」「详细说说」等指代性提问，具备对话记忆能力；
- 取消固定关键词硬编码，纯算法检索，借款合同、劳动合同、租房合同可直接替换使用，无需改动代码；
- 优化PDF文本分块策略，合理设置分块大小与重叠度，避免法律条款被截断，检索召回更完整；
- 重构LangChain调用链路，修复字典传参异常Bug，系统运行更稳定；
- 项目分层解耦：RAG核心、后端接口、前端页面独立拆分，仅启动api.py即可运行，部署更简便。

## 三、核心功能
- 读取本地合同PDF文档，严格基于文档原文精准问答；
- 支持多轮对话+上下文记忆，连续追问不丢失语境；
- 采用本地TF-IDF相似度检索，不依赖外网向量模型，国内网络可流畅运行；
- 前后端分离架构，搭配简约网页聊天界面，可直接用于项目演示；
- 无需部署重型大模型，仅调用DeepSeek API，轻量化、依赖少、易部署；
- 适配Windows、Mac系统，替换任意PDF业务文档无需修改核心逻辑。

## 四、技术栈
- 开发语言：Python
- 框架工具：LangChain、FastAPI
- 大模型：DeepSeek Chat
- 检索方案：本地 TF-IDF + 余弦相似度（零外网依赖）
- 前端界面：原生HTML

## 五、快速启动指南

### 5.1 安装依赖
```bash
pip install -r requirements.txt
```

### 5.2 配置 API Key
复制 `.env.example` 并重命名为 `.env`，填入个人 DeepSeek API Key。

### 5.3 替换 PDF 文档
将自有合同PDF放入项目根目录，可自定义文件名，同步修改代码内路径即可；默认支持各类法律、办公PDF文档，无需改动业务逻辑。

### 5.4 启动后端接口
```bash
python api.py
```
备注：无需单独运行main.py，api.py会自动加载RAG核心全部逻辑。

### 5.5 打开前端页面
双击 `index.html`，即可进入聊天界面开始多轮智能问答。

## 六、注意事项
- 项目采用本地TF-IDF检索，不依赖HuggingFace，无需下载额外模型，国内网络可直接运行；
- 所有PDF文档仅在本地读取，不上传、不对外泄露，隐私性强；
- V1.1版本已实现通用化，劳动合同、租房合同、普通业务文档均可无缝切换使用；
- 严格限制大模型仅依据文档内容作答，无相关依据时自动提示未找到相关内容，有效降低模型幻觉。

## 七、项目结构
```text
LegalRAG/
├── main.py            # RAG核心：PDF加载、文本分块、检索逻辑、提示词模板、问答链路
├── api.py             # FastAPI后端接口、跨域配置、多轮对话入参适配
├── index.html         # 前端聊天页面、本地对话历史缓存、接口请求交互
├── .env               # DeepSeek密钥配置文件
├── requirements.txt   # 项目依赖列表
└── 合同PDF文件         # 可自行替换任意PDF格式文档
```
